# Diode Characterization and Differential Temperature Sensor

I characterized a 1N4148 diode and built a differential temperature sensor using the temperature dependence of its forward voltage. An LM358 amplifier and a comparator drive an LED when the sensor diode is warmer than the reference diode.

The [final report](final-report.pdf) includes the circuit drawings, LTspice results, breadboard implementation, and measurements. It also describes matching the diodes and adjusting the reference network. The design targets were about 1 V per degree Celsius and an LED threshold about 5 degrees above the reference temperature.
