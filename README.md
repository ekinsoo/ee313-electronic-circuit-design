# Electronic Circuit Design Labs and Project (EE313)

This repository collects four labs and a thermocouple-controlled heater project I completed for EE313 at Bilkent University in 2024. The work covers circuit simulation in LTspice, schematic and PCB design in DipTrace, and hardware measurements.

## Project

The [thermocouple-controlled heater](project-thermocouple-heater/) uses an LM324-based instrumentation amplifier, a comparator, and a transistor switch to control a resistive heater. The reports cover the design, op-amp offset measurements, PCB layout, assembled board, and experimental results.

## Labs

| Folder | Topic |
| --- | --- |
| [lab-01-temperature-sensor](labs/lab-01-temperature-sensor/) | Diode characterization and differential temperature sensing. |

## About the files

The PDFs contain the circuit drawings, calculations, simulation plots, and hardware measurements. The project also includes a separate design report with the offset measurements and simulation work.

I kept this as a report archive: the original folders contain exploratory circuit and PCB revisions that are not consistently tied to the final hardware. Those files and generated simulation outputs are omitted. Student ID numbers and handwritten signatures have been removed from the public report copies; the original technical discussion is preserved.

These are historical course results. I have not rerun the simulations or repeated the hardware measurements for this repository. The individual notes point out limitations in the original reports.
